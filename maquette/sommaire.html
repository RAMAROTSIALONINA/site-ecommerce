Parcours de démonstration conseillé

  1. Accueil → catégorie « Épicerie » → fiche « Vanille bourbon » → Ajouter au panier.
  2. Panier : appliquer le code SAVA15 ou BIENVENUE10, choisir la zone de livraison.
  3. Commande : adresse (région, commune, fokontany, repère) → zone → paiement MVola (numéro 034…) → simuler la confirmation.
  4. Mon compte → Mes commandes → suivi et facture PDF.
  5. Back-office → Commandes : la nouvelle commande apparaît ; faire évoluer la livraison, confirmer un paiement, rembourser.
  6. Changer le rôle en haut du back-office (ex. « Comptable ») pour voir le contrôle d’accès.
  7. Espace vendeur → Commandes → « Colis prêt pour l’enlèvement ».
